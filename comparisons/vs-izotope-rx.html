CoProducer vs iZotope RX

Updated August 2026 · Surgery vs gates

RX is the right tool when you must paint out a chair squeak, a lip smack, or a wireless dropout in a spectral editor. CoProducer will not pretend to be that. Its repair path is loudness, true-peak safety, and a cautious high-pass when rumble/DC evidence is strong — then a report of what it refused to touch.

Use RX when the artifact is local in time-frequency. Use CoProducer when the question is “is this file allowed on a storefront, and what would a conservative delivery pass change?” You can run both: score in CoProducer, then open RX only for the hits the report flagged.
