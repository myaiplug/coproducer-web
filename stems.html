Split stems.
On your GPU.

RoFormer separation models run inside this tab with WebGPU. Nothing is uploaded and no server is involved. Pick a model, drop a bounce, play each stem and download it as WAV.

  • Models download directly from Hugging Face on first use, are checked against a pinned SHA-256, and are saved in this browser (resumable if interrupted). After the first run the tool works offline. You can clear the models at any time.
  • Best on desktop Chrome or Edge with a dedicated GPU. Without WebGPU it falls back to the CPU (multi-threaded where your browser allows it), which is slower. Use the Fast preview model in that case.
