Should you upload an unreleased master to the cloud?

NoDAW Labs · Lacquer Vol. 01

Only if you accept a vendor storing that file. Loudness, true peak, clip count, and phase can be measured on your machine. A cloud master is a product choice, not a requirement of the physics.

An unreleased bounce is often the most valuable object in the room: not yet registered, not yet public, still the only copy with unclipped stems behind it. Sending it to a $15/month club to “see what AI does” is a rights decision dressed as a workflow. You can ask for LUFS without asking a stranger to keep the WAV.

What actually has to leave the room

Nothing, for a delivery check. Integrated LUFS and true peak are computed from samples you already have. CoProducer’s desktop path is local. The optional web Analyze talks to an API you run at 127.0.0.1 — it is not “upload to get a master back.” The GitHub Pages site is static. If Analyze works, it is because an engine is running where you can see it.

Time saved: you skip the account, the queue, the “which genre preset,” and the second-guessing of a file you cannot fully unsay. You bounce, you measure, you decide whether the mix or the ceiling is the problem. That is a shorter afternoon than waiting on a cloud render you will A/B against the original anyway.

When upload is honest

If you want a third party to render a new master, the file must go somewhere. Read the terms. Assume training and retention unless the contract forbids both. Compare that to the field notes: vs LANDR and vs cloud mastering.

CoProducer is not claiming to be a better mastering engineer than a human with taste. It claims to be a meter and a conservative delivery pass you keep. Those are different jobs. Mixing them is how people upload a record to solve a true-peak overshoot.

Pro is a one-time $49 license, $34 with WEB30. The pitch is ownership of the meter, not a cheaper upload. Hear the local repairs on the A/B first; then decide whether a cloud needs the file at all.
Does the website upload my song to NoDAW?
The GitHub Pages site is static. Analyze only works when you (or a host you control) run the local API. The form does not ship a repaired file back.
Is local always better sounding?
Not automatically. It is better defined: you keep the WAV, you see the plan, you can refuse the high-pass.
