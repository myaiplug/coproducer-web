A release checklist that matches the meter

NoDAW Labs · Lacquer Vol. 01

Pass a bounce when integrated LUFS is within 1.5 LU of −14, true peak is ≤ −1.0 dBTP, clipped samples are 0, sample rate is ≥ 44.1 kHz, phase correlation is ≥ 0.2, and the CoProducer score is ≥ 90.

Print this once. Tape it above the bounce folder. The point is to stop using mood as a release criterion. “It feels loud” is not a store. The store has a lane. These six gates are that lane, written as a checklist so you do not re-litigate them on Friday night.

The six gates

GatePassIf it fails
Integrated LUFS−14 ± 1.5Gain / loudnorm, not another decorative limiter
True peak≤ −1.0 dBTPTrue-peak limiter last, then re-measure
Clipped samples0Go back to the unclipped mix if you still can
Sample rate≥ 44.1 kHzDo not bounce a 32 kHz MP3 and call it a master
Phase≥ 0.2Mix work. Auto-repair will not flip polarity
Score≥ 90Read the findings; listen

Order of operations that saves a recall: measure first. If clips are non-zero and you still have the session, fix the clip at the source. If clips are zero and true peak is high, cap last. If LUFS is hot and the mix still has punch, turn it down before you squash. If phase is the fail, do not buy a loudness tool. Buy time in the arrangement.

These are the same colors on the homepage A/B table. A leftover +0.04 dBTP after Crazy Stacy’s repair stays red on purpose. Green is not a mood. It is a gate.
