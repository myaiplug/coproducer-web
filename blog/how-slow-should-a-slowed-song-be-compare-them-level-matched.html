How slow should a slowed song be? Compare the same bars, level-matched

NoDAW Labs · Lacquer Vol. 06

There’s no right speed for a slowed version, so render a few and pick by ear, but compare the same bars at the same loudness. In our test the hook of a 140 BPM beat moved from 27.43 s to 39.18 s at TIME 70, ten seconds held 5.83 bars of the original but only 4.08 of the slowest render, and the slowed renders read up to 1.2 LU quieter before we matched them.

Four exports in a folder: 95, 85, 80, 70. You click between them in the file browser, each one starts at 0:00, and after a few rounds you pick one. Maybe it was the best speed. Maybe it was the one you heard last, or the one that happened to be loudest, or the only one where you got to the hook before you clicked away.

How far to slow is a taste call, and this essay covers how to think about it. This one is about making the comparison fair, so the speed you pick is the one you actually liked.

Render the batch from one bounce

Start from the same file and change one thing. In HalfScrew, keep WOW and the effects the same and move only TIME, and PITCH if you want it, then export each. The settings end up in the file names, so you know which is which later.

ScrewAI renders several strains from one file in a single batch (17 flavors in the drag-and-drop .bat version, 60+ in the app; the free browser demo does one strain at a time). Strains differ in EQ and effects as well as speed, so a strain batch is a flavor comparison, not a pure speed one. That’s fine, just know which question you’re asking. If a winner is named after the strain, read the speed back from its length before you write the BPM down.

What makes the comparison unfair

We wrote audition_reel.py to measure it. It builds a 32-bar beat at 140 BPM with a hook from bar 17, bounces it with peaks at −1 dBFS, and renders five HalfScrew settings with the tool’s resampler, WOW 0 and no effects. Then it measures each render and builds a blind audition: the same 8 hook bars from every version, turned down to the same loudness, in shuffled order, with the key printed separately.

# Picking a slowed speed: render a batch from one bounce, then compare the same 8 bars at the same loudness.
# Slowing = HalfScrew's resampler ported from halfscrew.js resample() (v=44): 4-point Hermite (HQ), WOW 0, no FX.
# Loudness = ITU-R BS.1770 integrated LUFS via pyloudnorm.
import numpy as np, soundfile as sf, pyloudnorm as pyln
from scipy.signal import butter, sosfilt
fs = 48000; rng = np.random.default_rng(5)
BPM = 140; beat = 60 / BPM; bars = 32; L = int(round(bars * 4 * beat * fs)); HOOK_BAR = 17

def hermite(y0, y1, y2, y3, f):
    c1 = 0.5 * (y2 - y0); c2 = y0 - 2.5 * y1 + 2 * y2 - 0.5 * y3; c3 = 0.5 * (y3 - y0) + 1.5 * (y1 - y2)
    return ((c3 * f + c2) * f + c1) * f + y1
def halfscrew_resample(a, ratio):
    n = int(np.ceil(len(a) / ratio)); pos = np.arange(n) * ratio; i0 = np.floor(pos).astype(int); f = pos - i0
    g = lambda k: np.where((k >= 0) & (k < len(a)), a[np.clip(k, 0, len(a) - 1)], 0.0)
    return hermite(g(i0 - 1), g(i0), g(i0 + 1), g(i0 + 2), f)

t = lambda sec: np.arange(int(sec * fs)) / fs
def place(hits, sound):
    y = np.zeros(L)
    for b in hits:
        i = int(round(b * beat * fs)); seg = sound[: L - i]; y[i:i + len(seg)] += seg
    return y
hp = lambda x, fc: sosfilt(butter(4, fc, 'highpass', fs=fs, output='sos'), x)
kick = np.sin(2 * np.pi * np.cumsum(49 + 120 * np.exp(-t(0.25) * 30)) / fs) * np.exp(-t(0.25) * 12)
sub808 = np.tanh(2.5 * np.sin(2 * np.pi * 49 * t(1.6))) * np.exp(-t(1.6) * 1.5) * 0.6
snare = (0.6 * np.sin(2 * np.pi * 200 * t(0.2)) + hp(rng.standard_normal(int(0.2 * fs)), 1500) * 0.5) * np.exp(-t(0.2) * 22)
hat = sosfilt(butter(4, [6000, 12000], 'bandpass', fs=fs, output='sos'), rng.standard_normal(int(0.05 * fs))) * np.exp(-t(0.05) * 90) * 0.3
def note(hz, sec): return 0.12 * sum(np.sin(2 * np.pi * hz * k * t(sec)) / k for k in (1, 2, 3)) * np.exp(-t(sec) * 3)
mix = (place([b * 4 + o for b in range(bars) for o in (0, 2.5)], kick) + place([b * 4 for b in range(bars)], sub808)
       + place([b * 4 + o for b in range(bars) for o in (1, 3)], snare) + place([i / 2 for i in range(bars * 8)], hat))
hook = sum(place([b * 4 + i for b in range(HOOK_BAR - 1, bars)], note(hz, 0.4)) for i, hz in enumerate((349.2, 415.3, 523.3, 466.2)))
mix = mix + hook
mix *= 10 ** (-1 / 20) / np.abs(mix).max()                        # bounce peaks at -1 dBFS
meter = pyln.Meter(fs)
hook_t = (HOOK_BAR - 1) * 4 * beat
print(f"Bounce: {bars} bars at {BPM} BPM, {len(mix)/fs:.1f} s, hook starts bar {HOOK_BAR} at {hook_t:.2f} s, {meter.integrated_loudness(mix):.1f} LUFS\n")

SETTINGS = [("TIME 95", 95, 0), ("TIME 100 PITCH -2", 100, -2), ("TIME 85", 85, 0), ("TIME 80", 80, 0), ("TIME 70", 70, 0)]
renders = {"original": (1.0, mix)}
for name, tm, p in SETTINGS:
    r = tm / 100 * 2 ** (p / 12); renders[name] = (r, halfscrew_resample(mix, r))

print(f"{'render':20}{'speed':>7}{'BPM':>7}{'length':>8}{'hook at':>9}{'8 bars':>8}{'10 s =':>9}{'LUFS':>7}")
lufs = {}
for name, (r, y) in renders.items():
    lufs[name] = meter.integrated_loudness(y)
    print(f"{name:20}{r:7.3f}{BPM*r:7.1f}{len(y)/fs:7.1f}s{hook_t/r:8.2f}s{8*4*beat/r:7.2f}s{10/(4*beat/r):6.2f} bars{lufs[name]:7.1f}")

quiet = min(lufs.values())
print(f"\nLevel match: turn each clip down to the quietest render ({quiet:.1f} LUFS), so nothing gets boosted into clipping")
order = list(renders); rng2 = np.random.default_rng(2026); rng2.shuffle(order)
reel, key = [], []
gap = np.zeros(int(1.0 * fs))
for i, name in enumerate(order):
    r, y = renders[name]; a = int(round(hook_t / r * fs)); b = a + int(round(8 * 4 * beat / r * fs))
    g = quiet - lufs[name]; clip = y[a:b] * 10 ** (g / 20)
    n = int(0.005 * fs); clip[:n] *= np.linspace(0, 1, n); clip[-n:] *= np.linspace(1, 0, n)
    reel += [clip, gap]; key.append(f"   clip {chr(65+i)} = {name:20} gain {g:+.1f} dB, clip LUFS after match {meter.integrated_loudness(clip):.1f}")
sf.write("audition_reel.wav", np.concatenate(reel), fs, subtype="PCM_24")
print("Blind order (audition_reel.wav, 1 s gap between clips). Key, for after you've picked:")
print("\n".join(key))

Reading the numbers

The hook moves. In the original it starts at 27.43 s. At TIME 95 it’s at 28.87, at TIME 80 at 34.29, at TIME 70 at 39.18. Jump every file to the same timestamp and you’re comparing different parts of the song. The hook in any render is at the original time divided by the speed.

Seconds aren’t bars. Ten seconds of the original is 5.83 bars. Ten seconds of the TIME 70 render is 4.08. If you audition by the clock, the slow version always gets less music, so it can sound emptier for a reason that has nothing to do with the speed. Eight bars is 13.71 s in the original and 19.59 s at TIME 70. Compare bars.

The slower ones read quieter. Nobody touched a fader, but the renders went from −20.4 LUFS for the original to −21.6 at TIME 70. Loudness meters count deep lows for less than the mids, and slowing pushes energy down, the same effect measure the peak again describes. In an A/B, whatever is a little louder tends to sound better, which this essay gets into. So the script turns each clip down to the quietest render, from −1.3 dB for the original to 0.0 for TIME 70. Turning down means nothing gets pushed into clipping, and the clips landed within 0.1 LU of each other, −21.5 to −21.6.

Order matters too. The reel plays the clips in a shuffled order and keeps the key out of sight until you’ve picked. The original is in there as well. Sometimes the honest answer is that the gentlest setting doesn’t change enough to be worth a release.

How to run the audition

  1. Render four to six versions from one bounce, the batch above, changing only the speed if speed is the question.
  2. Cut the same 8 bars from each. Start at the hook time divided by the speed, and make the clip 8 bars at the new BPM long.
  3. Match loudness by turning down. Any integrated LUFS meter works, your DAW’s or the analyzer on this site. Bring every clip down to the quietest.
  4. Listen blind, at one level, on your monitors and on a phone. Pick before you look at the key.
  5. Then go back to the full render of the winner. Measure its true peak, and if anyone will sing over it, check it lands on a semitone.
Level-matching is for choosing, not for shipping. Don’t release the turned-down audition clip. Measure and finish the winning render on its own.
How slow should a slowed song be?
There’s no single number. Render a few speeds from the same bounce and compare them blind and level-matched. Our five settings ran from a speed of 0.95 to 0.70, which took a 140 BPM beat to between 133.0 and 98.0 BPM.
Why does my slowed version sound quieter?
Loudness meters weight deep lows less than mids, and slowing moves energy down. In our test the original read −20.4 LUFS and the TIME 70 render −21.6, with no gain change.
How do I compare slowed versions fairly?
Compare the same bars, not the same seconds, at matched loudness, in a blind order. Turn the louder clips down to the quietest one instead of boosting.
Where is the hook in my slowed version?
At the original time divided by the speed. A hook at 27.43 s lands at 34.29 s at a speed of 0.80 and at 39.18 s at 0.70.
