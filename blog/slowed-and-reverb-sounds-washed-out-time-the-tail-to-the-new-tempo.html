Slowed + reverb sounds washed out? Time the new tail to the slowed tempo

NoDAW Labs · Lacquer Vol. 06

If your slowed + reverb version sounds washed out, the reverb you added on top is still ringing when the next snare lands. Slowing a bounce stretches the reverb already in it by the same ratio as the groove: in our test a 1.2-second tail at 140 BPM became 1.50 seconds at 112 BPM, and had decayed exactly as far, 42.7 dB, by the next snare. A 4-second reverb added after slowing was only 16 dB down by then. Set the new tail from the slowed tempo, not from habit.

Slowed + reverb needs that big hazy reverb. It’s half the sound. So you slow the song, put a long hall on the whole thing, and the hook sounds gorgeous. Then the verse comes in, the snare turns into a smear, the vocal sits behind a curtain and the hats are just gone.

Most people blame the slowing for that. Usually it isn’t the slowing.

What slowing does to the reverb that’s already there

Varispeed plays the whole bounce slower, so every reverb tail in it gets longer. It also pushes the snares further apart by exactly the same ratio, so the tail and the groove stretch together. We checked it in tail_check.py: a synthetic 1.2-second tail at 140 BPM with the snare on 2 and 4, slowed to 80% with the same Hermite interpolation HalfScrew uses. Then we added new reverbs of different lengths after slowing, and ported HalfScrew’s own reverb impulse from its source to measure it the same way.

# Slowed + reverb: what slowing does to a reverb that's already in the mix, and how much of a reverb
# added AFTER slowing is still ringing when the next snare lands. Synthetic signals, fixed seed.
import numpy as np
fs = 48000; rng = np.random.default_rng(7)

def ir(rt60, dur=None):                         # exponential noise tail, -60 dB at rt60 seconds
    n = int(fs * (dur or rt60 * 1.3)); t = np.arange(n) / fs
    return rng.standard_normal(n) * 10 ** (-3 * t / rt60)

def halfscrew_ir():                              # HalfScrew's reverb impulse (halfscrew-fx.js), ported line by line
    sr = fs; decay = 3.0; n = int(sr * (decay + 0.25)); pre = int(sr * 0.012); out = np.zeros((2, n))
    for c in range(2):
        seed = (0x9e3779b1 ^ ((c * 0x85ebca6b) & 0xffffffff)) & 0xffffffff; lp = 0.0
        for i in range(n):
            seed = (seed * 1664525 + 1013904223) & 0xffffffff
            noise = seed / 2147483648 - 1; t = i / sr
            k = 0.9 - 0.82 * np.exp(-t * 1.6); lp = lp * k + noise * (1 - k)
            env = np.exp(-6.9078 * t / decay); ramp = min(1, (i - pre) / (sr * 0.02))
            out[c, i] = 0 if i < pre else lp * env * max(0, ramp) * 2.2
    return out.mean(0)

def edc_db(h):                                   # Schroeder energy decay curve, dB re total energy
    e = np.cumsum((h ** 2)[::-1])[::-1]; return 10 * np.log10(e / e[0] + 1e-30)

def rt60_of(h):                                  # T20 method: fit -5 to -25 dB, extrapolate to -60
    d = edc_db(h); t = np.arange(len(d)) / fs; m = (d <= -5) & (d >= -25)
    slope = np.polyfit(t[m], d[m], 1)[0]; return -60 / slope

def level_at(h, sec):
    v = edc_db(h)[int(sec * fs)]; return v

def show(v): return 'below -60 dB' if v < -60 else f'{v:.1f} dB'

def slow(y, speed):                              # tape-style: time and pitch together, 4-point Hermite (as HalfScrew HQ)
    pos = np.arange(1, len(y) - 3, speed); i = pos.astype(int); f = pos - i
    y0, y1, y2, y3 = y[i - 1], y[i], y[i + 1], y[i + 2]
    c1 = 0.5 * (y2 - y0); c2 = y0 - 2.5 * y1 + 2 * y2 - 0.5 * y3; c3 = 0.5 * (y3 - y0) + 1.5 * (y1 - y2)
    return ((c3 * f + c2) * f + c1) * f + y1

bpm, speed = 140, 0.8
gap = 120 / bpm                                   # snare on 2 and 4: one snare every two beats
print(f"Beat: {bpm} BPM, snare every {gap:.3f} s. Slowed to {100*speed:.0f}%: {bpm*speed:.0f} BPM, snare every {gap/speed:.3f} s\n")

h = ir(1.2, 2.5)
hs = slow(h, speed)
print("1) Reverb already in the mix (baked into the bounce), then the whole bounce is slowed")
print(f"   {'':22}{'decay (RT60)':>13}{'snare gap':>11}{'tail left at next snare':>26}")
print(f"   {'original':22}{rt60_of(h):11.2f} s{gap:9.3f} s{level_at(h, gap):20.1f} dB")
print(f"   {'slowed to 80%':22}{rt60_of(hs):11.2f} s{gap/speed:9.3f} s{level_at(hs, gap/speed):20.1f} dB")

print("\n2) New reverb added AFTER slowing (snare every %.3f s)" % (gap / speed))
print(f"   {'reverb decay':22}{'measured RT60':>13}{'decay / gap':>13}{'tail left at next snare':>25}{'still ringing 2 snares later':>31}")
for rt in (0.6, 1.0, 1.5, 2.5, 4.0):
    r = ir(rt, max(3 * gap / speed + 0.1, rt * 1.3))
    print(f"   {rt:10.1f} s{'':11}{rt60_of(r):11.2f} s{rt/(gap/speed):12.2f}{show(level_at(r, gap/speed)):>22}{show(level_at(r, 2*gap/speed)):>28}")
hz = halfscrew_ir()
print(f"   {'HalfScrew reverb':22}{rt60_of(hz):11.2f} s{rt60_of(hz)/(gap/speed):12.2f}{show(level_at(hz, gap/speed)):>22}{show(level_at(hz, 2*gap/speed)):>28}")

print("\n3) Snare gap at common slowed tempos, and the decay that is 30 dB / 60 dB down when the next snare lands")
print(f"   {'BPM':>5}{'snare gap':>11}{'30 dB down':>12}{'60 dB down':>12}")
for b in (140, 120, 112, 100, 90, 70):
    g = 120 / b; r = ir(2 * g, 3 * g)
    print(f"   {b:5d}{g:9.3f} s{2*g:10.2f} s{g:10.2f} s   (check: a {2*g:.2f} s tail measured {level_at(r, g):.1f} dB at the gap)")

print("\n4) Delays added after slowing: time them to the new tempo")
for b in (bpm, bpm * speed):
    q = 60000 / b; print(f"   {b:5.0f} BPM: 1/4 = {q:.0f} ms, 1/8 = {q/2:.0f} ms, dotted 1/8 = {q*0.75:.0f} ms")

Reading the numbers

The reverb in the mix stays in proportion. At 80% the 1.2-second decay measured 1.50 seconds, and the gap between snares grew from 0.857 to 1.071 seconds. When the next snare hit, the tail had decayed 42.7 dB in both versions. It’s the same amount of space, just slower. If the original mix had air between hits, the slowed bounce still has it.

The new reverb is where the wash comes from. Anything you add after slowing only knows the new tempo. At 112 BPM a 1.5-second decay was 43.0 dB down by the next snare, about where the mix’s own reverb sat. A 2.5-second decay was only 25.6 dB down. A 4-second decay was 16.0 dB down and still at −32.1 dB two snares later. That’s tail stacked on tail: every hit is still ringing through the next two.

Long isn’t wrong. The slowed + reverb sound wants some overlap. The real question is how much. A handy way to think about it is decay divided by the snare gap. In our runs 1.4 sat like the original mix, 2.33 was the hazy sound, and 3.73 was the one where the groove started to dissolve.

Set the tail from the slowed tempo

With the snare on 2 and 4, the gap between snares is 120 divided by the BPM, in seconds. A decay as long as that gap is 60 dB down when the next snare lands. Twice the gap is about 30 dB down, which is a good place to start for the hazy sound.

  1. Slow first, then add the reverb, so you’re hearing the tail against the groove you’ll release.
  2. Work out the new tempo (original BPM × speed) and the snare gap (120 ÷ new BPM).
  3. Start the decay around twice the gap. Go shorter if the verse is busy or the vocal is dense, and longer on purpose for intros, interludes and outros.
  4. High-pass the reverb so the 808 and kick don’t get tails of their own. The reverb return essay has the filter settings.
  5. Leave room at the end of the file for the last tail to ring out, then check the peak again, since reverb stacks new peaks on top of the slowed mix.

HalfScrew puts its reverb after the slowdown, so it’s already hitting the slowed groove, and its export adds the reverb’s tail time to the end of the file. The tail itself is fixed: ported from the source, it measured about 2.29 seconds, a decay-to-gap ratio of 2.14 at 112 BPM, right in the hazy range. The reverb amount crossfades dry and wet, so on a busy beat the move is less amount, not a shorter tail. The SLOWED + REVERB strains are a quick starting point if you’d rather tweak from a preset.

Delays work the same way. Add them after slowing and time them to the new tempo: at 140 BPM an eighth note is 214 ms, at 112 BPM it’s 268 ms. A delay left at the old time drifts off the slowed grid. Delay time from BPM has the full table.
Should I add reverb before or after slowing a song?
After. Slowing stretches the reverb already in the bounce in step with the groove. The reverb you add after slowing is the part you control, so set it against the tempo you’ll release.
How long should the reverb be on a slowed song?
Start around twice the gap between snares. At 112 BPM that’s about 2.14 seconds, roughly 30 dB down when the next snare lands. Go shorter for clarity and longer for haze.
Why does my slowed + reverb version sound muddy?
The added tail is outlasting the space between hits. In our test a 4-second decay at 112 BPM was only 16 dB down at the next snare and still ringing two snares later. Shorten it or turn it down, and high-pass the reverb.
Does slowing a song make the reverb longer?
Yes, by the same ratio as the tempo. A 1.2-second tail became 1.50 seconds at 80%, but the snares moved apart by the same ratio, so it had decayed the same 42.7 dB by the next hit.
