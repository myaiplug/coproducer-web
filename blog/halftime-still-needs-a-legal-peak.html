Halftime still needs a legal peak

NoDAW Labs · Lacquer

Halftime makes a record feel heavier. It does not grant a pass on true peak. Stretch the file, then measure the file you will actually upload.

Why the peak moves

Slowing to 50 percent keeps pitch in place and doubles the length. Inter-sample peaks do not politely follow the waveform you saw at full tempo. A bounce that cleared −1.0 dBTP can sit over the line after the stretch, especially if the low end was already leaning on the limiter.

The useful order is simple. Print the slowdown. Run the same gates you trust on a normal master: clips at 0, true peak at or under −1.0 dBTP, loudness within 1.5 LU of −14 if a storefront will normalize it.

Hear the potion before you commit

HalfScrew is the small desk for that print. Drop the song on the display, set time toward halftime, export the WAV. It is a creative pass, not a master. If the screwed version is the one that ships, bring it back to the analyzer.

The browser desk is HalfScrew. Drop a song, export the slowed WAV, then meter it here if it has to ship.
Does halftime fix clipping?
No. It can hide a click in a longer file and still fail the codec.
Should the slow file match −14 LUFS?
Only if a platform will turn it up or down. Creative syrup can sit hotter. Delivery copies should not.
