Releasing a slowed version? Give it its own title, ISRC, BPM and key

NoDAW Labs · Lacquer Vol. 06

A slowed version is a new recording of the same song, so it ships with its own title, its own ISRC and its own BPM, key and length, and none of them match the original. In our delivery sheet, a 3:24 song at 140 BPM in F minor slowed to 80% became 112 BPM and 4:15, and its key landed 14 cents above C# minor rather than on any key. Write those numbers down when you export, not when the upload form asks.

The slowed version is done. You picked the speed, you slowed the bounce, it sounds like a late drive home. Then the distributor form opens, and every field still has the original’s answers in it: same BPM, same key, same length, same code. Click through and the store thinks it’s the same track, or worse, your notes do.

Tape-style slowing moves tempo, pitch and length together by one number, the speed. So the label copy for a slowed version isn’t a guess. It’s arithmetic you can do once, at export, while you still remember what you did.

What changes when you slow it

We wrote delivery_sheet.py to do that arithmetic for a made-up song, 3:24 at 140 BPM in F minor, at six real HalfScrew settings: four strains and two presets, with each one’s TIME, PITCH and effects taken from the tool’s source. It works out the speed, the semitone drop, the new BPM, the new length with and without the effect tail the export adds, how much longer the file got, and where the key lands. Then it prints the file names each tool would give you.

# Delivery sheet for a slowed version: what changes on the label copy when you slow a song.
# Speeds, strain settings, reverb/delay tails and the export filename pattern come from HalfScrew v=44
# (halfscrew-fx.js STRAINS + tailSeconds(); halfscrew.js export name). Example song: 3:24, 140 BPM, F minor.
import math
NOTES = ["C", "C#", "D", "Eb", "E", "F", "F#", "G", "Ab", "A", "Bb", "B"]
song = dict(file="night-drive.wav", title="Night Drive", seconds=204.0, bpm=140, key=("F", "minor"))

def mmss(s): s = round(s); return f"{s // 60}:{s % 60:02d}"
def key_after(semis):
    root = NOTES.index(song["key"][0]); near = round(semis); cents = round((semis - near) * 100)
    name = f"{NOTES[(root + near) % 12]} {song['key'][1]}"
    return name if cents == 0 else f"{name} {cents:+d} c"
def hs_name(base, t, p, w, mix=100, fx=True):   # halfscrew.js: base-HalfScrew-t..-p..-w..-mix..(-fx).wav
    return f"{base}-HalfScrew-t{t}-p{p}-w{w}-mix{mix}" + ("-fx" if fx else "") + ".wav"

# (label, TIME, PITCH, WOW, reverb, delay): strain values from halfscrew-fx.js; presets from halfscrew.js
rows = [("Half Triss", 89, 0, 0, 0, 0), ("Holy Tuss", 85, 0, 0, 55, 0), ("Wockk Classic", 80, 0, 0, 0, 0),
        ("Echo Ackt", 90, -1, 0, 28, 30), ("POTION preset", 100, -2, 40, 0, 0), ("DEEP preset", 70, -4, 60, 0, 0)]
print(f"Original: {song['title']}, {mmss(song['seconds'])}, {song['bpm']} BPM, {song['key'][0]} {song['key'][1]}\n")
print(f"{'setting':15}{'speed':>7}{'semis':>8}{'BPM':>7}{'length':>8}{'+ FX tail':>11}{'longer by':>11}  {'key':16}")
for name, t, p, w, rev, dl in rows:
    r = t / 100 * 2 ** (p / 12); semis = 12 * math.log2(r)
    tail = 3.0 if rev > 1 else (2.5 if dl > 1 else 0.0)        # tailSeconds(): reverb 3 s, delay 2.5 s
    body = song["seconds"] / r
    print(f"{name:15}{r:7.3f}{semis:+8.2f}{song['bpm'] * r:7.1f}{mmss(body):>8}{mmss(body + tail):>11}{round(body + tail - song['seconds']):>9} s  {key_after(semis):16}")
r10 = song["seconds"] / (song["seconds"] + 10)
print(f"\nSpeed-only change stays under 10 s longer only above {r10:.3f} ({song['bpm'] * r10:.1f} BPM) for this {mmss(song['seconds'])} song")
print("\nExport filenames (HalfScrew), so the bounce tells you what it is:")
for name, t, p, w, rev, dl in rows[:3]:  # strains load EQ, so the export carries -fx
    print(f"  {name:15} {hs_name('night-drive', t, p, w)}")
print("\nScrewAI names renders <file>_<Strain_Name>.<ext> (renderer.js): the strain, not the speed.")
print("Read the speed back from the lengths: speed = original length / slowed length (no FX tail on the clock).")
for fname, length in [("night-drive_Slow_Burn.wav", "4:22"), ("night-drive_Mildly_Slowed.wav", "3:52")]:
    m, s_ = map(int, length.split(":")); r = song["seconds"] / (m * 60 + s_)
    print(f"  {fname:31} runs {length} -> speed {r:.3f}, {song['bpm'] * r:.1f} BPM, {12 * math.log2(r):+.2f} semitones, {key_after(12 * math.log2(r))}")

Reading the sheet

BPM is the old BPM times the speed. 140 at 80% is 112.0. At the DEEP preset, 77.8. If you list beats or tag files for DJs, this is the number they’ll match against, so it should be the slowed one.

Length is the old length divided by the speed, plus the tail. Wockk Classic took 3:24 to 4:15. Holy Tuss has reverb on, and HalfScrew’s export lets the reverb ring 3 seconds past the end, so 4:00 became 4:03. Check that the ending rings out the way you want before it ships. This essay covers cut-off tails.

The key only lands on a key at whole-semitone speeds. The POTION preset drops exactly 2.00 semitones, so F minor becomes Eb minor, clean. Half Triss is 2 cents off the same key, close enough to call it Eb minor. Wockk Classic sits 14 cents above C# minor, Holy Tuss 19 above D minor, and DEEP 17 below G minor. For a key tag, write the nearest key, and keep the cents in your own notes. If anyone will sing or play over it, pick a speed on a semitone first.

It’s a lot longer than you’d think. Even the gentlest setting here made the song 25 seconds longer, and Wockk Classic 51. That matters for the code, below.

The release checklist

  1. Title. Keep the main title identical and mark the version: Night Drive (Slowed), or (Slowed + Reverb). If your distributor has a version field, put it there, so the slowed one groups with the original instead of looking like a new song.
  2. ISRC. Give it its own. An ISRC identifies a recording, not a song. The IFPI rule we covered in the 432 Hz alternate master essay says a speed-only change gets a new code once the length changes by 10 seconds or more. For this 3:24 song, anything slower than 0.953, about 133.5 BPM, crosses that line, so every slowed version on the sheet does. Distributors have their own rules on top, so confirm with yours. The songwriting underneath is the same song, so the writers and splits normally carry over.
  3. BPM, key and length from the sheet, not from the original’s metadata.
  4. Peaks. Slowing changes the peaks, and reverb adds new ones. Measure the slowed file, not the original master. Measure the peak again has the details.
  5. Format. Deliver it to the same spec as the original. Sample rate and bit depth covers the boring, important part.
  6. Clean version. If the original has one, slow the clean too, at the same speed, so the two still line up. That’s its own track and its own code as well. The clean version essay has the rest.

Let the file name do the remembering

HalfScrew writes its settings into the export name: t for TIME, p for PITCH, w for WOW, then the dry/wet mix, and -fx when the EQ or effects are in the render. So night-drive-HalfScrew-t80-p0-w0-mix100-fx.wav already tells you it’s 80% with no pitch shift and no wobble, and the BPM and key follow from that.

ScrewAI is built for making a batch: pick a file, select several strains, render them in one go (17 flavors in the drag-and-drop .bat version, 60+ in the app). Its files are named after the strain, like night-drive_Slow_Burn.wav, which is great for auditioning and says nothing about speed. Before you upload the one you picked, read the speed back from the lengths, original length divided by slowed length. A render that runs 4:22 from a 3:24 song is at 0.779, so about 109 BPM and a key 33 cents below C# minor. Seconds are rounded, so treat that as within a BPM or so.

Keep one line per version in your project notes: Night Drive (Slowed) · 0.80 · 112 BPM · C# minor +14 c · 4:15 · its own ISRC. It takes a moment at export and saves you working it all out again when the playlist pitch form asks.
Does a slowed version of a song need a new ISRC?
Usually, yes. An ISRC identifies a recording, and the IFPI rule we’ve covered says a speed-only change needs a new code once the length changes by 10 seconds or more. A 3:24 song crosses that at any speed below 0.953. Distributors have their own rules, so confirm with yours.
What BPM do I put for a slowed version?
The original BPM times the speed. A 140 BPM song at 80% is 112.0 BPM, at 89% it’s 124.6, and at the DEEP preset’s 0.556 it’s 77.8.
What key is my slowed song in?
Drop the key by 12 × log2(speed) semitones. Only whole-semitone speeds land on a key: F minor at 89.1% is Eb minor, but at 80% it sits 14 cents above C# minor. Use the nearest key for tags.
How long will my slowed version be?
The original length divided by the speed, plus any effect tail. A 3:24 song at 80% runs 4:15, and at 85% with reverb it runs 4:03 including HalfScrew’s 3-second reverb tail.
