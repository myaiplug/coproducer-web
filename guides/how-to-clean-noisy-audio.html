How to clean noisy audio

Updated August 2026 · Conservative gates only

Noise in a mix is not one problem. Hiss in a quiet verse, sub rumble under an 808, DC offset, and clipped transients each need a different tool. CoProducer’s auto-repair only fires when the meter evidence is strong enough that the fix is unlikely to thin the record.

What the engine will try

EvidenceActionWhat it will not do
Noise floor in the rumble window (~−70 to −42 dBFS), DC offset, or sub-bass dominating bass25 Hz high-passBroadband denoise / “AI vocal print”
LUFS far from −14 or true peak over −1.0 dBTPloudnorm, then a hard true-peak capMultiband glue, clipper, or “make it radio”
Clipped samplesLimit the output; caution staysReconstruct flattened transients
Phase < 0.1Caution onlyAuto stereo repair

That is why the web analyzer projects the post-repair numbers instead of rendering a “cleaned” file in the browser. The desktop app is where Pedalboard/FFmpeg actually write a WAV you can audition.

Order of operations

  1. Measure first. Guessing at EQ before LUFS/true peak is how mixes get smaller.
  2. Fix clips at the source if you still have the session.
  3. Then delivery: loudness + true-peak ceiling.
  4. Listen in mono after any width or phase warning.
